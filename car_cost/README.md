# Определение стоимости автомобилей

Проект посвящён прогнозированию стоимости автомобилей на вторичном рынке с использованием методов машинного обучения.

---

## Цель проекта
Разработать модель для предсказания рыночной стоимости автомобиля, ориентируясь на качество предсказания (RMSE ≤ 2500) и скорость работы модели (время обучения и предсказания).

---

## Задачи проекта
1. Загрузка данных и библиотек
2. Предобработка данных:
   - Приведение названий столбцов к snake_case
   - Приведение типов данных
   - Удаление дубликатов, исправление опечаток
   - Заполнение пропусков
3. Исследовательский анализ данных (EDA):
   - Статистика числовых и категориальных признаков
   - Визуализация (гистограммы, боксплоты, пайчарты)
   - Поиск и устранение выбросов
4. Корреляционный анализ и отбор признаков
5. Feature Engineering:
   - Создание признаков на основе даты (`relevance`)
   - Объединение признаков кузова и топлива (`vehicle_fuel_type`)
6. Подбор и обучение моделей:
   - Линейная регрессия
   - LGBMRegressor
   - CatBoostRegressor
7. Оценка моделей:
   - RMSE, MAE, MSE
   - Время обучения и предсказания
8. Выводы по лучшей модели

---

## Исследование данных
- Основная масса автомобилей зарегистрирована в 1995–2010 годах
- Большинство автомобилей имеют мощность 60–170 л.с.
- Пробег в основном около 140 тыс. км
- Наиболее популярные марки: Volkswagen, Opel, BMW, Mercedes, Audi, Ford
- Преобладает бензиновое топливо, механическая коробка передач
- Feature importance по phik: `brand_mod`, `registration_year`, `power`, `repaired`, `vehicle_fuel_type`, `kilometer`, `gearbox`

---

## Моделирование
- **Baseline model**: CatBoostRegressor (iterations=1000, learning_rate=0.05, depth=10)
- **Выбор признаков**: удалены `registration_month` и `postal_code` по feature importance
- **Подбор гиперпараметров** для LGBMRegressor и CatBoostRegressor
- **Лучший результат**:
  - **LGBMRegressor**: RMSE = 1627, MSE = 26 468 297, MAE = 10 207, время обучения 13.2 сек, время предсказания 7.3 сек
  - **CatBoostRegressor**: RMSE = 1713, MSE = 2 933 331, MAE = 1084, время обучения 50.4 сек, время предсказания 0.6 сек
- **Вывод**: LGBMRegressor — оптимальный выбор по качеству и скорости работы.
