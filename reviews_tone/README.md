
# reviews_tone

*Проект для оценки тональности отзывов: классификация комментариев на позитивные и негативные.* 

**Цель** — помочь интернет-магазину выявлять токсичные комментарии и отправлять их на модерацию.  

Критерии оценки:  
- **F1-score ≥ 0.75**  
- Важна метрика **recall** для выявления негативных отзывов.
  
**Шаги работы**
- Установка библиотек и необходимых констант.
- Загрузка данных и установка столбца "Unnamed: 0" в качестве индекса.
- Проверка данных на дубликаты и пропуски, выявление дисбаланса классов (≈89.8% позитивных, 10.2% негативных).
- Предобработка текста:
- 
1)Очистка от никнеймов, ссылок и хештегов с помощью регулярных выражений.
  
2)Лемматизация текста с помощью nltk.

- Разделение датасета на выборки с стратификацией по таргету.
- Векторизация текста с помощью TfidfVectorizer.
- Обучение моделей:
- 
1)Логистическая регрессия с подбором параметра C.
  
2)LightGBM (результат оказался хуже базовой модели, поэтому гиперпараметры не подбирались).

**Результаты и выводы**

Создана модель с удовлетворительным качеством. Основная метрика F1 достигнута, recall позволяет выявлять большинство негативных отзывов.
Для дальнейшего улучшения качества можно использовать BERT вместо подхода лемматизация + TfidfVectorizer.

**Стек технологий**

*Python, Pandas, NumPy, Matplotlib, Seaborn, NLTK, TextBlob, TfidfVectorizer, Logistic Regression, LightGBM, sklearn Pipeline, метрики ML (F1, recall, precision), tqdm*
