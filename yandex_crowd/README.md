# Анализ поиска в Яндекс Картинках

**Описание проекта**

В рамках проекта проведён анализ пользовательских запросов в поиске по картинкам за период 31 августа — 21 сентября 2021 года.

**Цель исследования** — проверить гипотезу о различии интересов пользователей на мобильных устройствах (touch) и компьютерах (desktop).

**Задачи**:
- Определить временной диапазон данных.
- Проанализировать количество запросов «ютуб» по платформам.
- Выявить топ-10 самых частотных запросов для desktop и touch.
- Изучить распределение трафика в течение дня.
- Определить контрастные тематики между мобильным и десктопным сегментами.

**Основные выводы**

- Запросы чувствительны к календарным событиям (1 сентября, презентация iPhone 13).

- touch-трафик выше по объёму, но Desktop активнее в рабочие часы.

- desktop чаще используется для учебных и рабочих задач (таблицы, шаблоны, печать).

- touch — для личного использования: поздравления, lifestyle-контент, быстрые ситуативные запросы.


**Используемые инструменты**: Python, Pandas, Matplotlib / Seaborn, SQL

**Результат**

Гипотеза подтверждена: интересы пользователей мобильных устройств и компьютеров заметно различаются и отражают разные сценарии использования.
